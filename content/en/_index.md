# Raven Pipeline Security

A Continuous Delivery Foundation project for securing CI/CD from code to cloud.

## Mission

Raven Pipeline Security is a vendor-neutral reference for embedding cybersecurity into CI/CD. It maps open-source security tooling to recognized frameworks so platform, DevOps, and security teams can apply controls across the delivery lifecycle—from source and prebuild through build, deploy, and post-deploy operations.

## Vision

We maintain a living guide that platform and DevSecOps teams can use to secure pipelines as standards evolve. The guide already follows the NIST Secure Software Development Framework. This site now also connects that work to the OpenSSF Open Source Project Security Baseline, the NIST AI Risk Management Framework, and the EU Cyber Resilience Act.
