## NIST Cybersecurity Resources and Publications

The National Institute of Standards and Technology (NIST) provides cybersecurity frameworks, standards, and technical guidance to help organizations secure the software development lifecycle. These publications address secure software development, artificial intelligence (AI), software supply chain security, DevSecOps, vulnerability management, and cybersecurity governance.


### 1. Secure Software Development and DevSecOps

| NIST Publication | Title | Description | Status | Link |
|---|---|---|---|---|
| SP 800-218 | Secure Software Development Framework (SSDF) Version 1.1 | Foundational secure software development practices covering organizational preparation, software protection, secure production, and vulnerability response. | Final | [NIST Publication](https://csrc.nist.gov/pubs/sp/800/218/final) |
| SP 800-218 Rev. 1 | Secure Software Development Framework (SSDF) Version 1.2 | Proposed updates to the SSDF addressing secure and reliable software development, delivery, and improvement. | Draft | [NIST Publication](https://csrc.nist.gov/pubs/sp/800/218/r1/ipd) |
| SP 800-204D | Strategies for the Integration of Software Supply Chain Security in DevSecOps CI/CD Pipelines | Guidance for integrating software supply chain security, provenance, attestations, and artifact verification into CI/CD workflows. | Final | [NIST Publication](https://csrc.nist.gov/pubs/sp/800/204/d/final) |
| NIST IR 8397 | Guidelines on Minimum Standards for Developer Verification of Software | Recommendations for static analysis, automated testing, fuzzing, threat modeling, and software dependency verification. | Final | [NIST Publication](https://csrc.nist.gov/pubs/ir/8397/final) |

| NIST Publication | Title | Description | Status | Link |

### 6. NIST Resources Mapped to the CI/CD Cybersecurity Guide

The following table maps relevant NIST publications to the three phases of the CI/CD Cybersecurity Guide.

| CI/CD Phase | Security Focus | Recommended NIST Publications |
|---|---|---|
| Phase 1: Code and Prebuild | Secure coding, threat modeling, dependency security, AI development, and security planning. | SP 800-218, SP 800-218A, IR 8397, AI 100-1, AI 600-1, AI 100-2 |
| Phase 2: Build and Deploy | Software supply chain security, SBOMs, provenance, artifact integrity, automated security testing, and container security. | SP 800-204D, SP 800-161 Rev. 1, SP 800-218, SP 800-190 |
| Phase 3: Post Deployment | Continuous vulnerability management, runtime security, vulnerability disclosure, patch management, and remediation verification. | SP 800-40 Rev. 4, SP 800-216, SP 800-53 Rev. 5, SP 800-190, SP 800-218 |
