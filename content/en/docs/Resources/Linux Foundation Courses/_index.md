## Free OpenSSF and Linux Foundation Cybersecurity Education

The Open Source Security Foundation (OpenSSF) and Linux Foundation provide free educational resources covering secure software development, AI security, software supply chain security, DevSecOps, vulnerability management, and cybersecurity compliance.

These courses are available online at no cost and provide practical training for developers, DevOps teams, platform engineers, security professionals, and open-source maintainers.

**Training catalogs:**

- [OpenSSF Education and Training](https://openssf.org/training/)
- [Linux Foundation Free Training](https://training.linuxfoundation.org/full-catalog/?_sfm_price=0)
- [Linux Foundation Cybersecurity Training](https://training.linuxfoundation.org/cybersecurity/)


### Recommended Free Learning Path

For practitioners who are new to software security, the following progression provides a practical starting point.

| Step | Course | Learning Objective |
|---|---|---|
| 1 | Developing Secure Software (LFD121) | Understand secure software development fundamentals. |
| 2 | Secure AI/ML-Driven Software Development (LFEL1012) | Learn secure practices for AI-assisted software development. |
| 3 | Introduction to DevSecOps for Managers (LFS180) | Understand how security fits into CI/CD workflows. |
| 4 | Automating Supply Chain Security (LFEL1007) | Learn SBOMs, provenance, and software supply chain controls. |
| 5 | Securing Your Software Supply Chain with Sigstore (LFS182) | Learn software artifact signing and verification. |
| 6 | Securing Projects with OpenSSF Scorecard (LFEL1006) | Automate assessment of open-source project security. |
| 7 | Understanding the EU Cyber Resilience Act (LFEL1001) | Understand software cybersecurity regulatory obligations. |

### 5. Education Mapped to the CI/CD Cybersecurity Guide

The following table maps OpenSSF and Linux Foundation courses to the three phases of the CI/CD Cybersecurity Guide.

| CI/CD Phase | Security Focus | Recommended Courses |
|---|---|---|
| Phase 1: Code and Prebuild | Secure coding, threat modeling, dependency security, AI-assisted development, application security, and security planning. | Developing Secure Software (LFD121); Secure AI/ML-Driven Software Development (LFEL1012); Understanding the OWASP Top 10 (SKF100); Authentication & Authorization for Web/API (LFEL1004); Introduction to JavaScript Security (LFS184) |
| Phase 2: Build and Deploy | Software supply chain security, SBOM generation, provenance, artifact signing, dependency security, and CI/CD security. | Automating Supply Chain Security (LFEL1007); Sigstore (LFS182); OpenSSF Scorecard (LFEL1006); Introduction to DevSecOps for Managers (LFS180) |
| Phase 3: Post Deployment | Vulnerability identification, security assessments, vulnerability management, regulatory compliance, and ongoing security practices. | Security Self-Assessments (LFEL1005); Developing Secure Software (LFD121); Understanding the EU CRA (LFEL1001); Security for Software Development Managers (LFD125) |
