# Raven Pipeline Security

Un proyecto de la Continuous Delivery Foundation para proteger el CI/CD desde el código hasta la nube.

## Misión

Raven Pipeline Security es una referencia independiente de proveedores para incorporar la ciberseguridad en CI/CD. Relaciona herramientas de seguridad de código abierto con marcos reconocidos para que los equipos de plataforma, DevOps y seguridad apliquen controles a lo largo del ciclo de entrega, desde el código y la precompilación hasta la construcción, el despliegue y las operaciones posteriores.

## Visión

Mantenemos una guía viva que los equipos de plataforma y DevSecOps pueden usar para proteger pipelines a medida que evolucionan los estándares. La guía ya sigue el NIST Secure Software Development Framework. Este sitio también conecta ese trabajo con la OpenSSF Open Source Project Security Baseline, el NIST AI Risk Management Framework y el Reglamento de Ciberresiliencia de la UE.
